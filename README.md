# NTCX — NOVA concept site

A static landing page prepared for GitHub Pages.

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

Push this folder to a GitHub repository. In the repository settings, enable GitHub Pages from the `main` branch and the repository root.

## Publishing with GitHub Pages

1. Create an empty GitHub repository and push this project to its `main` branch.
2. Open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. The included workflow publishes every push to `main`.
